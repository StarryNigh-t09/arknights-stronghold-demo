# 社区数据接入决策层 · 静态审查（2026-11-10）

范围：world/lib/{knowledge,decide,drive}.js、world/src/tools.js；契约按 world/data/*.json 实读；用 node 导入模块跑小样本（cwd=world/）验证。

## 一、会崩

**1. tools.js:661 `peek()` 没导入 → ReferenceError**
顶部 import 从 run.js 没引 peek。wz_auto_run 打完整局后在返回前抛错，战报与复盘全丢。
改：import 行补 `, peek`。

## 二、会导致判断错

**2. tools.js:424 `levelupCost: levelupCostTable()` 把半张表当整表**
levelupCostTable() 只返回 {1:5}（其余 money 为 null 被跳过），adviseRest 直接拿它查表（decide.js:275、317），Lv2 起 upCost=undefined，升级分支永不进。实测 Lv2/第6回合/12 资金 → `reroll`；同参数换 levelupTableFromEconomy(economy().levelup) → `levelup → 3`。同玩模式第 2 回合起听不到升本。
改：`levelupCost: levelupTableFromEconomy(economy().levelup)`；或让 levelupCostTable 返回 `{...DEFAULT_LEVELUP_COST, ...out}`。

**3. 打包后五份 JSON 全丢，且静默降级**
knowledge.js:120 依次找 world/data、DATA_DIR(=assets)、仓库 data；但 world/package.json:31 的 files 没有 data，install.mjs:52 的 SKIP 也含 data。装进 extensions 后三处全不存在。按 lib+assets 模拟装机实测：economy()/covenantStrength() 全空、levelupCostTable()={}、section 只剩表头，不报错。
改：构建/安装时把五份 JSON 拷进 assets（或 files 加 data、SKIP 去掉 data）。

**4. knowledge.js:171-173 附加盟约的键取错字段**
数据用 `n`（"精准"），代码 `c.name || c.id` 退成拼音 `jingzhun`。26 键里 15 个拼音 → covenantBonus / adviseDraft / wz_know 的 covenant 分支按中文名查全落空，附加盟约评级等于没接；index() 还多出拼音条目。
改：`const name = c.name || c.n || c.id`。

**5. decide.js:165 查不到 "B（被削）"**
4 条附加盟约的 tier 就是这个值，大写化后仍不是 S/A/B 档，即使修好上一条也拿不到权重。
改：先 `String(t).trim().toUpperCase().match(/^[SABCD][+-]?/)?.[0]` 再查表。

**6. decide.js:71-78 负权重吃掉「已激活」加分**
炎（C，-1.5）已激活：1.2-1.5=-0.3，`bonus > best.bonus`（初值 0）不成立，整条盟约连理由一起丢。实测 拜松 → bonus 0、reason ""。不会拉负，但「已在叠」信号没了。
改：best 初值 -Infinity，返回前 `Math.max(0, bonus)`。

**7. decide.js:279-290 checklistFor 没有回合过滤**
「第 1 回合只买一阶（1–2 块）」命中 /买/，第 6 回合仍挂在买卡清单；/卡/ 也太宽。当前数据里「升」字没误进 buy，规则一改就会串。
改：buyPriority 加 from/to 按 round 过滤，或收紧正则。
