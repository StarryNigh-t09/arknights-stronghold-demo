# 夜间成果 · 2026-11-12 03:2x

## 一句话
落位手势找对了：**拖到格只是「放入」，松手要朝某个方向滑一下才算确认**；起手时长根本不是关键（0ms 也能拎起）。
纯手势从 2.2s 压到 0.57s，端到端从 5.5s/人 压到 4.2~4.3s/人。代价是发现后期崩盘的真因：**场上站满 10 个后配额恒为 0**，这个不是手势问题。

## 1 落位机制（真机实测，不是猜）
三步：
1. 按住待命区干员精灵中心（≈徽章 +(47,88)）按住 **20ms**；
2. 分 12 步、**150ms** 拖到目标格心，松手 → 进入「待确认」态：全场绿格 + 红色「点击取消」+ 半透明白幽灵 + 头顶 ∧ 箭头。判据：截图里绿格像素数从 ~30 跳到 1e5（阈值 3000）。
3. **确认 = adb shell input swipe**：从格心 (x, y-50) 滑到 (x, y-200)，400ms。滑的方向就是选朝向（facing=right 时向右滑）。

命门：
- 确认必须用 `adb shell input swipe`，minitouch 做同样动作无效（事件密度不同）。松手(UP)事件本身是送达的——getevent 抓到了 TRACKING_ID ffffffff + SYN_REPORT，游戏收到了却仍停在待确认，所以才需要第二段。
- 落点必须是该干员的合法格；不合法时游戏把幽灵吸到最近合法格（实测差 76~140px，`snapTile()` 会跟过去），按落点去滑 = 滑在空地 = 取消。
- 判成功**只能看「待命区少一张牌」**，绿格归零不算（取消也归零）。
- 点一下牌（110ms 短按）会打开详情面板并拉近镜头，不会拎起；镜头一动所有坐标就漂，所以按偏了要重扫甲板，不能沿用旧点。

## 2 起手时长扫描（54 次真机，同一张牌每种 3 次）
判据＝进入待确认态。

| hold(ms) | 成功 | | hold(ms) | 成功 |
|---|---|---|---|---|
| 0/10/20/30/40/60/70/80/90/100/120/150/200/250/300/400/600/800 | 每组 3/3 | | move 220/300/420（hold 20） | 各 3/3 |

结论：**起手按住多久不影响**（旧结论「90ms 拎不动」是因为当时只有单点 down、没有连续移动）。真正影响的是移动段：
move 150ms → 平均拖拽 922ms；220 → 956ms；300 → 980ms；420 → 1077ms。最小配方 hold 20 + move 150 + confirm 400 ≈ **0.57s 纯手势**。

## 4 后期崩盘的真因（配额）

- 配额 0 时：牌能拎起、能进待确认、确认也发了，**游戏就是不收**（4 次尝试花 44s，一个都没上去）。

- 已加的闸门（world/lib/drive.js）：① OCR 读 0 不等于真 0 → 试放 1 个定夺；② 落位被拒 + 配额读作 0 连续 2 次 → 收手，不写 map-issues；③ 整备区 ≥6 张时本回合先不买；④ 第 1 回合学到的合法格池 <5 个不采用。

## 8 试过但没成的（别重走）
- **快速模式（COOP_FAST_BATCH=1）**：为了省掉每张牌 1.2s 的甲板复核，试了「整批不逐张扫、末尾扫一次」。单次上场确实从 4.1s 掉到 **3.1s**，但**一张都上不去**——因为甲板收牌会左移，不重新扫就还在按原来的最右那张（按在空位上）。回合末复核会诚实报「实际上场 0 个」。要救它得先有一条便宜办法重新定位甲板，暂时**默认关**（代码留在 drive.js，opts.fastBatch / 环境变量 COOP_FAST_BATCH）。
- **上滑确认用 minitouch**：无效，必须 adb shell input swipe。
- **点/长按/拖已上场的干员**（想卖人或撤退）：无任何反应，不弹面板也不换位。

## 9 04:58 实拍：满员后的死局长什么样
截图 world/.tmp/now-0458.png：回合 8、血 **1/13**、规程等级 3、场上 8 个干员打成一团、待命区还站着 **9 张**、钱 **18**。
- 场上容量就是 8 个（这局从第 4~6 回合起就满了）；满了以后「剩余可放置角色」恒为 0。
- 于是每回合：拖牌 → 不弹待确认 → 换格 → 再没反应 → 记 4 次失败（~36s），一张没上。
- 同时钱涨到 18 花不出去：买卡被「整备区 ≥6 张」的闸门拦住，升级又受「每回合最多升一次 + 目标等级（第 8 回合 = 4 级）」限制。
- 结果就是血一路掉到 1。**这不是手势问题，是策略问题**：满员之后要么能把场上的人换掉/卖掉，要么就该把每回合的钱全砸进升级或干脆攒着，而不是继续堆待命区。
