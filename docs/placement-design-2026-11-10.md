## 二、打分公式（去掉重叠项）

对每个候选格 `cell` 和方向 `dir`：

```
score = w1 * 罩住的行进路线格数
      + w2 * 罩住的友军数          // 医疗专用
      + w3 * 离红门推进度          // 重装贴脸用
      + w4 * 高台/栅栏格安全加成    // 敌人不走的格子
```

| 职业 | w1 | w2 | w3 | w4 | 说明 |
|---|---|---|---|---|---|
| 医疗 | 低 | **高** | 0 | 高 | 最后方，罩住最多友军 |
| 重装 | 中 | 低 | **高** | 低 | 贴红门侧吃伤害、阻挡 |
| 狙击/术师 | **高** | 0 | 中 | **高** | 罩住最长路线，优先安全格 |
| 近卫 | 高 | 0 | 中 | 中 | 同上，可站地面 |
| 先锋/辅助/特种 | 中 | 中 | 中 | 中 | 先当输出用 |

**硬约束**：
- 医疗永远最后方（离红门最远的一排）。
- 栅栏格（灰喉左边那种）敌人不走 → 远程优先放这。
- 攻击范围面板一格 = 地图一格，直接映射。

## 三、朝向

`facing = argmax_dir( 罩住的行进路线格数 )`，平局朝红门。
等价于「范围最长方向 ∩ 罩住更多敌人路线」。
