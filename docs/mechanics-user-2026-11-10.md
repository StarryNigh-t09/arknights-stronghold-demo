# 卫戍协议：用户口述的机制（2026-11-10 12:31 / 12:43）

来源：用户本人两次口述整理。这些细节 PRTS 和攻略视频里没有写清楚，优先信这个；
和别处冲突时以这份为准，并在下面注明冲突。

## 1. 资金

- **通常每回合清零**（所以「花光」是对的，不是保守策略）。
- 例外：开局策略效果可以让钱不清零，例如**坎诺特**。
- 实况里那种「越滚越多」是**倒转**玩法：花 2 块打出 3 块的效果。
- 推论：`decide.js` 现在「有剩钱就尽量花」的方向没错；要补的是「攒不起来的钱买什么最划算」，
  以及识别坎诺特/倒转类的开局效果后再改策略。

## 2. 冻结 / 刷新

- **冻结** = 锁定当前商店，下一回合不自动刷新。
- **刷新** = 换一批干员（花钱）。
- 现在的实现是「钱够就刷」，冻结基本没用过；后面要按「等对子」的场合才冻结。

## 3. 三合一与特殊商店

- 3 张同名（同阶）干员合成：**原来的低级干员直接变成高级**（1 阶 → 2 阶），不额外占格。
- 合成后**底下商店会变成特殊商店，随机刷出几个免费的高阶干员**。
- 干员卡左上角的罗马数字（Ⅰ/Ⅱ/Ⅲ）是**阶**，不是等级序号；商店卖的都是 1 阶。

## 4. 卖干员

- 甲板干员可以卖，**普遍回 1 点资金**；有些干员**卖掉时触发特性**。
- 卖的三类：凑不成对子的废卡、前期过度的低阶卡、卖掉能触发效果的卡。
- 还有一种：2 块买的干员，下回合卖掉能多 1 块（因为资金每回合清零，卖价按当回合算）。
- UI：把甲板干员拖到**右下角「拖拽至此售出 +1」**那块黄色区域（截图上见过，未实机验证）。

## 5. 上场 / 下场 / 换位

- 场上干员**可以下场**：光标压在干员脚下那格 → 长按 → 拖到**甲板任意空格** → 松开。
- **不会重排**（甲板保持原位，这点和之前观察一致）。
- 休整期内**可以直接在场内换格**（不下场也能改位置）。
- **战斗中完全不能操作**，只能看 —— 所有摆位必须在整备期做完。

## 6. 部署位上限

- 「剩余可放置角色」是**固定**的，除非有道具效果；**商店升级不会增加**。

## 7. 用户给的战略方向

1. 至少一个**医疗放后排**，攻击范围要能**覆盖最前面的重装**。
2. 其余买**输出型**干员，可以带几个**辅助**。
3. **凑羁绊很重要，决定后期上限**；B 站攻略大多在教怎么凑羁绊和叠羁绊效果。
4. **升级商店可以公式化**：什么时候升几本、为什么，让我去查别人的做法。
