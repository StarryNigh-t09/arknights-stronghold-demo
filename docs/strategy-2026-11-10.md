## 一、决策：升本 / 刷新 / 冻结 / 卖卡 / 什么时候补强

### 1. 钱的基本法

- **钱不能存，必须在当局花完。** 每回合给的钱随回合数上涨，越到后面越富，所以「前期穷着过」是正常的。
  > 「但是没办法存下来的 / 所以这边的话呢你的钱要在当局内花完」——BV144WJ6fEDC（fact）
  > 「就比如说现在回合数越高 / 那么这边提供的值就越高」——BV144WJ6fEDC（fact）
- **卖干员只回收 1 块。** 买低阶再卖是纯亏，所以不要把「卖卡换钱」当成运营手段，它只是腾格子。
  > 「你买了一个干员卖掉 / 他只会获得固定的一块钱」——BV144WJ6fEDC（fact）
- **本期经济被削，别按上一期「倒转滚钱」打。**
  > 「然后呢这个版本呢对于经济发育这一块呢 / 也是不是那么顺畅 / 卡的比较死」——BV1wpWp6FEki（fact）
  > 「因为这次经济类的海克斯呸 / 合约被削了之后 / 像是那种投资人啦 / 远见 / 属于能开就开 / 不能开就算了 / 也不强」——BV1HaW46zEN2（fact）

### 2. 升到几本

- **不是固定答案，看阵容：** 前期阵容四级够用；要 C 到后期（大炎这类）才考虑升满六本。
  > 「如果是打前期阵容的话 / 是四级够用 / 但如果说你是要C到后期的阵容 / 比如说炎国这样的阵容 / 那么这边就得考虑升到满级」——BV144WJ6fEDC（fact）
- **主流打法是「不升六、烂在五本」**，因为六本卡池脏，好卡就那几张，还会把五本的好卡稀释掉。
  > 「然后你直接不升不升六本 / 你直接一直用五本去碰六本就好了 / 六本的卡池非常的脏 / 好用的就那么几个」——BV1iLWW6XEUk（fact）
  > 「如果没有星级的话 / 或者打算就直接烂在五本」——BV1k1WW6AEx7（fact）
  > 「我们不升六 / 就是不升六 / 一直不升」——BV1iLWW6XEUk（fact）
- **三四本之间提升不大**，为了升本放弃找本家牌不划算。
  > 「升三本的话找牌其实找的就不是本家的牌 / 在三四本的提升其实并没有那么大」——BV1HaW46zEN2（fact）

### 3. 什么时候升 / 什么时候补强

- **有对子先拿对子，可以「慢升本」。** 这是所有决策里最硬的一条。
  > 「嗯嗯这个地方可以升本 / 但是我们好像可以找对碰 / 我们有对子 / 一定要优先拿下 / 后面就好打很多了」——BV1iLWW6XEUk（fact）
  > 「那就慢升本拿慢升本全拿了啊 / 有对碰有对碰 / 找对碰是一定不会错的哦」——BV1iLWW6XEUk（fact）
- **升三看战力。**
  > 「也只是一个大概三回合升二 / 四回合或者五回合升三 / 看场上的战力是否足够」——BV1CwWW6aEjh（fact）
- **什么时候该补强（刷新找牌）而不是升级：** 手里有对子、或者缺关键卡时，钱花在刷新上；反过来，什么都不缺又没对子可追，才把钱丢进升本。
  > 「嗯像现在这种 / 我们什么都不差了 / 又没有对子 / 那你升一下本也是可以的」——BV1iLWW6XEUk（inference：这是「没对子才升本」的反向读法）
- **关键卡到手就停本 D 牌。** 乌萨斯拿到「唯一 + 霍尔海雅」后停在四本，不再升本，专心对子。
  > 「我们可以考虑升到四本 / 或者说我们是已经在四本碰到的 / 我们就在这开始不升本D牌 / 找到足够多的对子去把动和给找出来」——BV1CwWW6aEjh（fact）

### 4. 什么时候刷新

- **一二本随便刷**，不用省。
  > 「nice jo1本随便刷就行」——BV1iLWW6XEUk（inference：原文口语，指 1 本卡池随便刷）
- **三本只为一个目标刷**：莱塔尼亚刷黑键，乌萨斯刷霍尔海雅；摸到就走。
  > 「雅拉就是三本的时候疯狂的找黑键 / 然后找到黑键A亚卡拉就升四 / 然后开始疯狂的找这个纯爱」——BV1iLWW6XEUk（fact）
- **四本停本刷对子**，用三合一去对五阶卡，约 5~6 次对子能出目标。
  > 「用三合一去对差不多五六次吧 / 再加上寻护模块 / 一般来说是能兑出来啊」——BV1CwWW6aEjh（fact）
- **五本刷艾雅法拉/缪尔赛思**，继续用刷新而不是升本换质量。

### 5. 什么时候冻结

- **正规用法：五/六本的关键启动卡先冻结，等把等级拉上去再回来买**，用等级差跳过随机。
  > 「在五阶或者六阶的环境下 / 你可以通过锁定把这里有一个冻结键冻结它 / 然后冻结完了之后 / 你的话呢可以到时候拉完等级之后 / 再去把它买掉」——BV144WJ6fEDC（fact）
- 实况里的用法：**对子还差一张、但想下回合再拿**，先冻结货架。
  > 「这里我们有一个对碰了 / 但是我们想要下回合再拿 / … / 我们冻结一下这把非常火非常非常火」——BV1iLWW6XEUk（fact）

### 6. 什么时候卖卡

- 只在一张卡**占格子且不再服务体系**时卖；因为卖价固定 1 块，不存在「靠卖赚钱」。
  > 「有个一本的月灵把谁卖了 / 不是都不是很舍得吗 / … / 把你卖了」——BV1iLWW6XEUk（fact：实况里为腾格子卖低星）
- 中后期**低星过渡卡必须换掉**，不是留着凑数。
  > 「到中期就可以把这两边 / 中后期就可以把这两个低星干员给换掉了啊」——BV1HaW46zEN2（fact）
- **1 块钱的卡（真理）见到就买**，卖也只卖 1 块，留着能吃三合一进阶。
  > 「那么真理因为只卖一块钱 / 我建议就是见到就买 / 我们可以等到上四本以后再进行一个进阶」——BV1CwWW6aEjh（fact）

### 7. 花钱优先级

> 「一般来说有条件的还是先把阵容凑出来之后 / 咱们再去考虑这种装备的问题」——BV144WJ6fEDC（fact）

不成体系的武器加成是浪费钱（作者原话「那实际是蛆啊」）；只有转职器（阿戈尔重任/银国短刃/维多利亚锤/萨尔贡浓茶）才值得为特定阵容买。

## 没查到的

1. **「刷新一次花几块钱、每回合刷几次算合理」没有硬数字。** 两个作者只说「1 本随便刷」「有对子优先」，没有给出刷新费用曲线或次数上限。
2. **升店费用的具体递减表没在 11-08 之后的视频里听到。** 只有「钱随回合数上涨」和「四级够用/满级」这两条定性说法；每级具体要多少钱、每回合降多少，本期视频没人念。
3. **「卖卡换钱」作为主动策略没找到任何支持。** 唯一相关的原话是「卖只返 1 块」，所以本文件把它定性为腾格子手段，并没有「靠卖卡周转经济」的打法。
4. **冻结键每回合能用几次、冻结几个格子**，没人讲；只讲了「关键卡先冻，升完本再买」这一种用法。
5. **分歧未解决：二本要不要停留。** 莱塔尼亚作者说二本不碰，乌萨斯作者说二本稍停一会儿。本文件两边都保留，没有强行统一。
6. **「小猫」是哪位干员没确认。** 字幕只出现「小猫」，效果是「直接加上限」，没念全名；不排除是 ASR 简写。同理「动核」也未确认全名（乌萨斯五阶目标卡）。
7. **「对子优先级」缺一个反例边界**：什么时候该放弃对子去升本，只有一句「什么都不差又没对子才升本」，没有更细的阈值。
