## 一、今天真正的根因：数字 OCR 一直没真正工作

**证据**：`C:/Maa/resource/PaddleCharOCR/det/` 是**空目录**（这个模型只有 rec）。
`sidecar/ocr.py` 的 `_stage_models()` 要求 det+rec+keys 三件齐全，缺 det 就判失败并把暂存目录删掉，
于是 MaaFramework 每次都报：

```
[ERR][OCRResMgr.cpp][L167] Failed to load rec [name=PaddleCharOCR]
[ERR][OCRer.cpp][L156] OCRSession not loaded
```

等级（Ⅰ/Ⅱ/Ⅲ）、剩余可放置名额、钱数，全靠 PaddleCharOCR 认数字 —— 它没加载，这些读数就退到
PP-OCR 全量识别或兜底，于是出现：
- `名额读数 0（整备区 3 张）` 紧接着又 `剩余名额 2`
- `认人失败（没读到名字）`
- `整备区张数不可信（木台被遮住）→ 沿用上次 N 张`
- `盟约账（场上 0 + 整备区 0）：还没数出盟约`

**修法**（已落盘）：`_stage_models()` 缺 det 时借 PaddleOCR 的 det 占位；缓存复用前核对
`rec.onnx` 大小与 `C:\\Maa` 源一致（旧缓存是 8.9MB / 10.7MB，源是 12.1MB / 21.2MB，一直用旧的）。
修完 `texts()` 真的返回字符了，`test/slotsocr.test.mjs` 的 `slots-1-split.png` 从 null 变 1。
