## 23:44–00:05 的回归失败与定位（重要）

23:44 起跑 12 回合整局，日志 `_run-night2.log`。结果：**R1–R2 一张卡都没买（bought 为空），血量 26→21→17**，之后脚本卡住不再写日志。

根因（已修）：23:47 我给 `senseRun` 加的「vision 误判兜底」把屏幕名写成了 `'wz_rest'`，而 `autoRest` 的守卫比较的是短名 `'rest'`（`if (st.screen !== 'rest') return {ok:false}`）。于是**每个休整期都直接返回「不在休整期」，一次买卡、升级、上场都不会执行**。
修法：兜底里改成 `st.screen = 'rest'`，并加注释说明短名约定。`node --check` 通过。

修后现场单测（脚本 `world/scripts/_resttest2.mjs`，只跑一个休整期）：
```
第4回合 钱7 中心Lv1 → levelup 2
  升到 Lv2（升级费 2→8）
第4回合 钱5 中心Lv2 → buy 角峰
第4回合 钱3 中心Lv2 → buy 角峰
第4回合 钱1 中心Lv2 → freeze 角峰
```
截图确认：LEVEL II、钱 1、甲板出现两个角峰、商店显示「解冻」。买卡链路恢复正常。

教训（已写进 LEARNINGS）：**改屏幕状态名之前先 grep 谁在做比较**；短名与长名混用会让守卫静默失败，表现为「什么都没发生」，不报错。
