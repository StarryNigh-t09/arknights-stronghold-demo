# 卫戍协议·规程：商店刷新与冻结决策规则

采集：2026-11-10 · 只采信 2026-11-08 之后的内容 · season_start 2026-11-08 16:00

## 一句话结论
钱不能存 → 「省」没有意义，只有「花在刷、买、升哪一边」的取舍；升级费每回合 -1 但一升级就重置 → 早升和等降价互斥；冻结是整排栏位级别的跨回合锁，只该用来跨过「这一回合买不了」的窗口。

## 分问回答

### Q1 什么时候该刷新
- 成本基准：每次 1 资金，资金不足 1 不能刷（R01）。
- 阶段节奏：1～2 本随便刷（R03）→ 3 本只为目标卡刷（R04）→ 4 本停本刷对子、预算 5～6 次三合一（R05）。
- 「钱多于多少才刷」：没查到硬阈值（R06）。
- 「剩几张卡时刷」：没查到按栏位剩余数给判据的来源。

### Q2 什么时候绝对不该刷新
- 手里有对子、还能凑三合一 → 先拿对子（R07）。
- 这一块钱买了也变不成对子/三合一，而刚好够升本 → 升本（R16 + R14）。
- 补充：刷新本身不会「浪费」，因为钱回合末清零（R02）——不该刷的理由是机会成本。

### Q3 冻结的正确用法
- 冻什么：整个剩余栏位一起冻（R08），不能只挑一张。
- 为什么有效：休整期只自动刷「未被冻结」的位置（R09）。
- 典型场景：5～6 本关键卡先锁、升完级再买（R10）；对子差一张留到下回合（R11）。
- 什么时候不冻：栏位全是过渡卡/垃圾（R13）。
- 是否影响刷新计数：机制上没有「刷新次数」资源（R12）。

### Q4 刷新与升级抢钱，先做哪个
- 能立刻变成对子/三合一 → 刷（R07/R16）；不能 → 升（R14）。
- 升级的双重收益：加栏位 + 解锁等阶（R15）。
- 时间陷阱：升级费每回合 -1，但升级后下一级立刻重置（R14）→ 拖一轮等于放弃降价积累。

### Q5 免费刷新的叠加
- 「补给」：接下来 2 次刷新免费，可叠加（R17）。
- 奥斯塔（2 阶）：1 次，精锐 2 次（R18）。
- 忍冬（3 阶）：1 次，触发 2 次后升级，至多 3 次（R19）。
- 技巧：攒到升完本再连刷（R20，推断 low）。
