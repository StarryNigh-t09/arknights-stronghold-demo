# 手动一回合录制 · 2026-11-10 21:12

## 是什么
用户（Dr.别压力一只鱼）在模拟器里手工打了一回合休整期，全程只读录制：
- 触摸事件：`_rec/touch.log`（`getevent -lt /dev/input/event4`，Xiaomi Touchscreen，Type B 多指，0–1080 × 0–1920）
- 逐帧截图：`_rec/0000.png` … `0079.png`（约 0.7 秒一帧，共 80 帧）
- 解析结果：`_rec/actions.json`（screen 坐标）、`_rec/actions_raw.json`（设备 raw 坐标）
- **回放脚本：`_rec/replay.txt`**（minitouch 命令，28 个动作，总时长 86.5 秒，按原时间间隔）

## 关键结论
1. 触摸事件能完整录下来：28 个动作，全部带起止坐标与毫秒级时长，无丢失。
2. raw ↔ screen 换算确认：`screen_x = raw_y`，`screen_y = 1079 − raw_x`。
3. 回放走 minitouch `-f` 文件模式即可，和线上拖动同一通道。

## 与自动流程的差异（要写进代码的）
1. 升级商店：她点的是左侧 LEVEL 条（x≈344, y≈903），不是顶部「规程等级」。
2. 收起商店：点右下角助理方框任意位置（x 1700–1800, y 900–950），不必精确点「收起 ×」。
3. 放干员：长按 ~2 秒（比我们现在的 450ms 长得多）再拖；松手后**必须再长按定朝向**。
4. 装备：先点一下装备（选中）再长按拖，和我们「直接长按拖」不同，可能是她先确认是哪件。
5. 卖干员：拖到右下 (1760,943) 售出区，松手即卖。

## 回放方法
```
adb -s 127.0.0.1:16416 push _rec/replay.txt /data/local/tmp/replay.txt
adb -s 127.0.0.1:16416 shell "/data/local/tmp/minitouch -f /data/local/tmp/replay.txt"
```
注意：局面已变（商店刷新、场上人数、血量都不同），直接回放会打到别的目标，只能当「动作库」用，不能当「结果复现」。
