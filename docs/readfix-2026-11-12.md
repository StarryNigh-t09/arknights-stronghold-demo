# 三处读数修复 + 卖卡实测（2026-11-12 上午）

一句话：甲板张数、名额、卖卡通道三件事都在真机上验过并修完了，13 个单测套件全绿（181 条断言 0 失败）。

## 1. 甲板张数：数「站在木台上的干员」，不数场上道具

**根因（看截图确认）**：场上道具（蓝色飞行器 / 青色球 / 黑箱）头顶挂着**同款**罗马数字深灰牌，3 个一排、间距 142，和真整备区干员行的几何完全一致。旧规则「取最靠下的多成员行」在整备区空着时会选中道具行 → 报「整备区 3 张」→ 布阵反复拖幽灵点。

**修法**：加木台锚点。
- 木色判据 `r>=150 & g>=120 & b<=150 & (r-b)>=45 & (g-b)>=10`，x 200..1700 逐行计数。
- 折叠态底部亮带恒定 **y 862..982**（逐行亮木像素 >1100；上方地图地面只有 650~760）。
- 商店展开时底部被面板盖住，计数掉到 <150 → 返回 `lowConfidence`，调用方沿用上次张数，不覆盖成 0。
- 取**最靠下**的合格带，不取最长的（镜头平移后上方会多一条更长木带，按长度会选错）。
- 顺带修掉「甲板只有 1 张被读成 0 张」：单成员行在木台带内就照收。

**落盘**：`sidecar/deck.py` 新增 `bench_rail()` / `bench_rows()`；`lib/run.js` `scanDeckChips` 走 rail-first，fallback 带 `lowConfidence:true`；`lib/drive.js` 遇低置信沿用 `LAST_BENCH_N`。

**验收**：`node test/deckcount.test.mjs` → **tests 14 / pass 14 / fail 0**（7 张夹具：甲板空 / 1 道具 / 3 道具 / 4 道具+1 人 / 1 人 / 2 人 / 商店展开走 fallback；另加「真甲板按压点 y≈880」）。

## 2. 名额：不是读不到，是读到**错值**

**根因**：`read_slots_left` 在标签行被 OCR 断句时，兜底会去扫任意文本的行尾数字：
- `traces/decision-2026-11-12T00-13-36-763Z/step-021.png`：标签被切成 `["剩余可放置角色","10"]`（10 是金币徽章）→ 返回 **10**，真值 1。
- `decision-2026-11-12T00-32-11-933Z/step-010.png`：标签 + 单独成块的「6」→ 旧版返回 **3**（商店价签），真值 6。

读成错值比读成 None 更坏：布阵会以为还有一堆名额。

**修法**：只认「说过剩余 / 放置」的那一块；它自己没数字时，只在**同一横带**里找被切开的数字块；再不行裁标签右侧窄条放大 6 倍重读；仍没有就返回 None。

**连带 bug（更致命）**：`drive.js:837` 原来是 `Number(opts.slotsLeft) <= 0`，而 `Number(null) === 0` —— OCR 没读到名额时被当成「名额用满」，连续两次落位被拒就收工。`decision-log.jsonl` 里 round 7 / 8 的 slotsLeft 正是 null。现在只有读到**有限数**且 ≤0 才算用满。

**验收**：
- `node test/slotsocr.test.mjs` → **4/4 过**（slots-1-split→1、slots-6-split→6、slots-3-shopopen→3、slots-1-inline→1）。
- `node test/quota-null.test.mjs` → **3/3 过**（静态锁：不许再出现裸 `slotsLeft) <= 0`，必须有 `Number.isFinite(quotaNum)` 守卫，null 必须映射成 NaN）。

## 3. 卖卡：真机通了，坐标改了

**实测（回合 7，钱 10、甲板 1 张）**：从甲板卡 (1414,882) 拖到 **(1770,920)** → 钱 10→11、甲板 1→0。

- 面板实测边界 x 1657..1880 / y 780..1065（裁图 `.tmp/sellzone.png` 按 2 倍换算），中心 (1770,920)。旧值 `SELL_ZONE=[1840,860]` 贴右边缘。
- **不需要先进待确认态**，休整期直接拖就行。
- 起手时长从 700ms 降到 20ms（14 步 × 40ms）。

**路径验证（生产方式 `sellDeckUnit`）**：买 1 张（钱 11→9）→ 卖 → 钱 10、甲板 1→0，`moneyPlus1:true / benchDown:true`。
