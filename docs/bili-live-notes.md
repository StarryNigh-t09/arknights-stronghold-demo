## 0. 先纠正一个结构误解：商店 ≠ 待命区

「从下方卡槽拖到格子」这句话把两个界面混成了一个。实测画面里它们是上下两层：

- **底层 = 商店**（5 张卡，带阶级 I/II/III、价格 1/2/3、盟约标签、干员名），旁边是「升级 6」「冻结 S」「刷新 1 D」「收起 A」。
- **战场下缘那一排 = 待命区**：已经买到手的干员站着等上场，头顶有 ⏸ 和罗马数字（阶级）。

证据：BV1VWWN6vEkW（4:57，33 万播放）00:56–01:03 连续帧——待命区 3 个干员在约 5 秒内全部上阵，右侧「剩余可放置角色：3」同步读到 0；同帧下方商店 5 张卡仍在，只是变了灰。

**实测到的「时长」（粗粒度，唯一测得到的数）**：00:57.5 待命区还有 3 个干员，01:03.5 已全部落位、配额归 0 → 摆 3 张卡总共 **≤6 秒**，平均每张 **≤2 秒**。抽帧间隔 0.25–0.5s，精度到不了 100ms 级。

**所以「买卡」和「摆人」是两步**：买卡把干员放进待命区（不进战场），摆人是从待命区拖到格子。自动化如果从商店卡槽起手拖，逻辑上就永远拖不到战场——这与台账里 79 条「牌没离手」的失败模式吻合。

## 1. 摆放操作五问（逐条）

### a) 是拖拽还是点选
**拖拽（drag-and-drop）。置信度：中高（未截到悬空中间帧，见下）。**

- 直接证据：游戏自己的 UI 文案就是拖拽语义——右下角常驻红框 **「拖拽至此售出 +1」**（BV1VWWN6vEkW 01:00、01:03.5 帧）与 **「拖拽至此销毁」**（房间 278778，2026-11-11 23:40 帧）。
- 间接证据：待命区干员在 00:57→01:02 之间逐个消失、格子上逐个出现，期间没有任何「点卡片 → 卡片高亮选中 → 再点格子」的两段式选中态。
- **不确定**：没有截到「卡/干员跟在指针上悬空」的那一帧。抽帧间隔最快 0.38s（ego_screenshot 往返 + seek 刷新），仍可能整段错过一次 0.2–0.4s 的拖拽。

### b) 在卡上停留多久才开始移动（长按时长）
**不确定。** 素材 30fps、浏览器抽帧实际 2–2.6 fps，分辨不出 100–300ms 级的起手停顿。要测这个数只有两条路：真机 minitouch 慢放录屏，或把 BV 视频下载到本地用 ffmpeg 逐帧（本次 yt-dlp 拉 B 站流被 RST：`Connection aborted (10054)`，三个重试全失败）。

### c) 松手时指针落在格心还是偏下/偏右
**不确定。** 同上，像素级落点在 2 fps 抽帧里不可判。录播里能看到鼠标指针（BV1VWWN6vEkW 01:00 帧指针压在干员身上），但松手瞬间没抓到。

### d) 拖拽过程中画面有什么变化
**有变化，已看到三类：**

1. **可放置格变绿**：布阵阶段战场上能放的格子显示为绿色地块，未开放区域仍是沙色（BV1VWWN6vEkW 00:57、01:02 帧）。敌人范围用红框标（房间 278778）。
2. **装备拖拽有白色菱形范围预览**：拖/悬停在装备（如对讲机）附近时，目标区域外套一圈带四角标记的白色菱形，即该装备的作用范围（BV1VWWN6vEkW 01:00、01:03.5 帧）。注意这是**装备**的预览，不是干员格高亮。
3. **销毁/出售区常驻右下**：`拖拽至此售出 +1`（自己局）/`拖拽至此销毁`（他人局）——拖拽过程中把卡丢进去就卖掉，自动化走位要避开。

另外：买不起的商店卡不是消失，而是**变灰并标「无法购买」**（BV1VWWN6vEkW 00:59 帧，此时金币不足）。

### e) 放上去之后卡槽里的卡是否立刻消失
**分两种，别混：**

- **待命区干员**：落位后立刻从待命区那一排消失，站到格子上（BV1VWWN6vEkW 00:57 → 01:02，3 个待命干员全部上阵，`剩余可放置角色` 3 → 0）。
- **商店卡**：不会被「摆」走，只有买走才变灰；买走后的位置显示灰卡「无法购买」而不是空槽（同一视频 00:59）。

## 3. 整局节奏（顺带记的）

- 回合数：房间 278778 抓到「回合 18」（23:40 帧）与「回合 22」（23:48 帧）→ **4 个回合约 8 分钟，平均 ≈2 分钟/回合**；BV 教学里抓到「回合 2」。顶部居中会显示「休息一下」= 布阵/整备阶段。
- 一回合的可见顺序（BV1VWWN6vEkW 00:56–01:04 连读 + 直播对照）：**布阵（待命区拖人上格，看剩余可放置角色）→ 点「准备就绪」→ 战斗 → 回合结算 → 回到商店（升级/刷新/买卡/冻结）→ 下轮布阵**。

## 4. 对自动化最有用的四条

1. **起手点必须落在待命区那一排，不是商店卡槽**——商店卡拖不出战场，这是「牌没离手」最容易的来源。
2. **摆放有配额**，「剩余可放置角色：N」归零后再拖不会落位；程序要先读这个数，否则把「配额满」当成「拖动失败」反复重试。
3. **「收起 A」是原生折叠按钮**，不是手势；折叠商店再开甲板/装备的方案成立，但要记得收起后商店卡位置整体上移/隐藏。
4. **右下角「拖拽至此售出 +1」是陷阱区**：拖拽轨迹若扫过右下角，会把干员当废卡卖掉。走位要走上半场再入格。
