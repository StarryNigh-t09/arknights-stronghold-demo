# 干员 Q 版小人 · 战场（带武器）视角

PRTS 干员页「干员模型」SpineViewer 导出的**战场正面**定帧：视角下拉选 `正面`（个别干员该项叫 `战斗`），背景切「透明」，点「导出 PNG」。

- 生成时间：2026-11-13
- 数量：**143 个 `<干员名>.png`**（`world/data/portraits.json` 全部 key，一个不缺）
- 目录：`coopanion-arknights/world/assets/chibi-battle/`
- 体积：28.0 MB 合计，单张 107–399 KB（均值 205 KB）

## 1. 图片属性（PIL 全量核验，见 `_image_stats.json`）

| 项 | 值 |
|---|---|
| 尺寸 | 1000×1000，RGBA（colortype 6） |
| 背景 | 全透明，四角 alpha=0 |
| 姿态 | 战场 Idle 定帧，武器完整展开，正面略偏右 |
| 人物占画面 | alpha 覆盖率 0.043–0.199，均值 **0.077** |
| 人物像素范围 | bbox 宽 201–568，高 267–547 |
| 校验 | 143/143 通过，0 坏图 |

与 `../chibi/`（基建 Relax 无武器）的区别：同一干员的**脸/配色一致，但肢体姿态、武器、披风展开程度不同**，换装皮肤未单独导出（每干员只导默认皮肤）。

## 2. 三个特殊条目

| 干员 | 情况 |
|---|---|
| `浊心斯卡蒂` | 她的视角选项是 `战斗 / 基建`（不叫「正面」），已按 `战斗` 导出 |
| `盟约·辅助干员` | 只有 `正面 / 背面`，导出的正面是持枪士兵（非干员造型） |
| `“暴躁铁皮”` | 只有 `正面`，导出的是一台机器 |

前一条与 `../chibi/` 里同名文件不同（`战斗` vs `基建`）；后两条与 `../chibi/` 同名文件**字节完全相同**（它们本来就只有正面可导）。

## 3. 复现

脚本：工作区根目录 `_chibi_battle.tpl.js`（`__NAMES__` 换成名字数组，交 `ego_script` 执行）。流程与 `../chibi/README.md` 相同，只把视角偏好改成 `['正面','战斗','基建','背面']`、输出目录改成 `chibi-battle`。

实测 7–8 秒/人，每次 `ego_script` 120 秒上限约 12 人，143 人约 18 分钟。

## 4. 用途提醒

战场视角虽然带武器、更接近游戏内表现，但仍是**正面舒展站姿、无地面阴影、无 UI 描边**；截图里的小人通常是 3/4 侧身、肢体收拢、脚下一个椭圆阴影。做模板匹配时建议：按 alpha bbox 裁剪 → 按最长边归一化 → 在 alpha 掩膜上做归一化互相关，先取 top-k 再核，别指望单阈值一次命中。
